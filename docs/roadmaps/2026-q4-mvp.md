## Success metrics (blueprint §9)

| Metric | Target |
|---|---|
| Time to first published trip | < 10 minutes |
| Independent onboarding | Most pilot sellers finish setup without help |
| Routine edit speed | Price/capacity update < 30 s |
| First real booking | Within 14 days for active pilot sellers |
| Repeat use | Sellers return to manage another departure/booking |
| Booking reliability | Zero overbooking or cross-seller exposure |
| Willingness to pay | Some active sellers commit to a paid plan |
| Support burden | Declining over the pilot |
